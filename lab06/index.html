What I Learned in Lab 05

In Lab 05, I learned about website design and usability. I learned that a website should be organized and easy to navigate. The CRAP design principles helped me understand how contrast, repetition, alignment, and proximity can make a page easier to read.

I also learned that good design should make information clear for visitors. I can use these ideas to improve the layout of my own website.

what i learned in lab 06

In Lab 06, I learned about the importance of responsive web design and layout. This is important when creating a webpage because you want to make sure people can access and use your website on different devices without having issues. Learning about media queries was interesting because they allow you to change the layout of a webpage depending on the screen size. For example, a webpage can display its content in one column on a mobile phone and two columns on a larger screen. I also learned how CSS Grid helps organize the content and make the webpage easier to use on different devices.
